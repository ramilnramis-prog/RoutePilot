Plan

Opening a plan reads it through GET /api/plans/{id}. “Create / open the DEMO plan” calls POST /api/plans, which returns the same deterministic fixture every time instead of duplicating it.

Map (Leaflet + OSM-compatible tiles)

The line drawn between the stops is synthetic straight-line geometry: it is the route order the engine returned, joined by straight segments. It is not road routing and carries no road distance, no turn instructions and no traffic.

First-stop recommendation (advisory)

A recommendation is advisory and NOT an applied decision. It is recomputed live for this request, it is not plan state, and it does not change the plan: the driver decides whether to accept it or choose another stop (D4/D11/D32).

What this build does NOT do

Read from the API's own capability report (GET /api/health, not_implemented_capabilities, route_modes and timezone_data) - not from a list written in this page. An unimplemented capability is never presented as working (D16).

RoutePilot recommends, the driver decides. Synthetic demo data is never presented as real routing, traffic or opening hours (spec sections 33/34; D15/D16/D23/D32).
